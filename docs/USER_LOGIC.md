# 点亮中国 · 用户与房间逻辑说明

> 版本：v=20261005t（2026-10-11）
> 适用对象：全家使用、小白用户

---

## 一、核心概念（先搞懂这两组词）

### 1. 本机身份 vs 房间成员

| | 本机身份 | 房间成员 |
|---|---|---|
| 是什么 | 这台设备（浏览器）上的用户档案 | 房间里所有人的名单 |
| 存哪儿 | 浏览器 localStorage，只在这台设备上有 | 云端 KV，所有设备共享 |
| 大厅里在哪看 | 「本机身份」区 | 「房间成员」区 |
| 能做什么 | 点亮足迹、切换、改名、删除 | 只读查看（看名字、看足迹数） |
| 换浏览器后 | 没了（除非认领回来） | 还在 |

**一句话**：本机身份是"你在这台手机/电脑上的化身"，房间成员是"这个家庭群里都有谁"。

### 2. 房间

- 一个房间 = 一个家庭群，用 6 位数字码标识（如 542591）
- 可选设 4 位数字密码（如 2024），家人输密码就能进，不用背 6 位码
- 房间有房主（创建者），只有房主能改密码、改名
- 一个人可以加多个房间，一台设备也可以有多个本机身份

## 二、本机身份的完整生命周期

### 创建

- 首次打开网站，自动创建一个本机身份（默认昵称"我"）
- 大厅「本机身份」区可手动添加（如给孩子建一个）

### 切换

- 大厅「本机身份」区点一下就切换
- 切换后地图显示的是这个身份的足迹
- 点亮操作记在这个身份名下，自动同步到云端

### 认领（核心功能：换设备找回足迹）

**场景**：换了手机/浏览器，本地是空的，但云端有你的足迹。

**流程**：
1. 大厅 → 加入房间 → 输入房间码/密码，或直接从"所有房间"列表点选
2. 预览房间成员
3. **新加入时自动弹窗**："请选择你的身份"，列出房间里除你之外的所有成员 + "我是新成员"
4. 选一个已有成员（如"爸爸"）→ 他的足迹合并到你当前的本机身份
5. 你的昵称、配色、足迹全部变成"爸爸"，以后点亮就记在他名下

**认领是合并，不是替换**：如果你本地已经点亮了 3 个省，"爸爸"有 10 个省，合并后你有 13 个省（取并集）。

**认领不可撤销**：选之前想清楚。

### 删除

- 大厅「本机身份」区目前没有删除按钮（防误操作）
- 如需清理重复身份（如两个"我"），联系管理员处理

## 三、房间的完整逻辑

### 创建房间

1. 大厅 → 创建家庭房间
2. 输入房间名（如"我们家"），可选设 4 位数字密码
3. 得到 6 位房间码，自动成为房主并进入房间

### 加入房间（三种方式）

| 方式 | 操作 |
|---|---|
| 房间码 | 输入 6 位数字码 → 预览 → 确认 |
| 密码 | 输入 4 位数字密码 → 自动找到房间 → 预览 → 确认 |
| 浏览列表 | 点"加入房间"，下方列出所有房间，点一个 → 预览 → 确认 |

**加入时如果输的昵称和房间里有人重名**，会问"你是 TA 吗？"→ 点"是"走认领流程。

### 房主特权

- 在「我的房间」列表，房主的房间多一个「密码」按钮
- 点「密码」可重设 4 位密码，留空则清除（恢复只能用房间码加入）
- 密码全站唯一，重复会提示换一个

### 退出房间

- 「我的房间」列表点「退出」，本地房间记录移除
- 云端数据不受影响（你的足迹还在，只是这台设备不显示这个房间了）
- 想回来重新加入即可

## 三、典型场景走一遍

### 场景 A：爸爸换了新手机

1. 新手机打开网站 → 自动创建本机身份"我"（空足迹）
2. 点"家庭" → "加入房间" → 看到"所有房间"列表 → 点 542591
3. 预览显示爸爸、妈妈、逍逍、遥遥
4. 弹窗"请选择你的身份" → 选"1. 爸爸"
5. 足迹合并，昵称变成"爸爸"，地图显示原来的足迹 ✅

### 场景 B：妈妈第一次用

1. 妈妈手机打开网站 → 本机身份"我"
2. 爸爸把密码（如 2024）发到微信群
3. 妈妈点"加入房间" → 输入 2024 → 预览 → 确认
4. 弹窗选身份 → 选"妈妈" → 认领 ✅
5. 或者选"我是新成员" → 以新身份加入（如果妈妈之前没点亮过）

### 场景 C：一台 iPad 全家共用

1. 大厅「本机身份」区添加 4 个身份：爸爸、妈妈、逍逍、遥遥
2. 每人玩之前先切换到自己的身份
3. 点亮的足迹自动归到对应身份名下，同步到云端
4. 在各自手机上也能看到全家人的足迹（通过「房间成员」区查看）

## 四、数据存在哪儿

| 数据 | 位置 | 说明 |
|---|---|---|
| 本机身份列表 | 浏览器 localStorage | 换浏览器就没了 |
| 当前身份的足迹 | localStorage + 云端 KV | 点亮后自动同步 |
| 房间信息 | 云端 KV | 所有设备共享 |
| 房间成员名单 | 云端 KV | 所有设备共享 |

**云端是源头**：只要认领成功，足迹就从云端拉回本地。本地数据丢了不怕，云端有备份。

## 五、常见问题

**Q：为什么"本机身份"里有两个"我"？**
A：之前测试时重复创建了。认领完成后可以清理，目前需手动处理。

**Q：认领后原来的本地足迹会丢吗？**
A：不会，合并是取并集，两边的足迹都会保留。

**Q：密码忘了怎么办？**
A：房主在大厅「我的房间」点「密码」重设。非房主问房主要。

**Q：房间码和密码有什么区别？**
A：房间码是系统生成的 6 位数，唯一标识房间；密码是房主设的 4 位数，好记。两个都能用来加入。

**Q：别人知道我的房间码/密码，能改我的足迹吗？**
A：能看到全家人的足迹，但改的是他自己的本机身份。除非他认领了你的身份——所以密码只发给家人。

**Q：退出房间后数据还在吗？**
A：在。退出只是这台设备不显示这个房间了，云端数据完整。重新加入即可恢复。
