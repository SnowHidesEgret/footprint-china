# 5A 数据契约（给 agy）

## 数据文件
`maps/scenic-5a.json` — 数组，共 359 条（2026-10 口径）。

### 字段
| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 稳定 ID（1..359），打卡 key 用 `5a:{id}` |
| `name` | string | 官方名称，如"八达岭—慕田峪长城旅游区" |
| `p` | string | 省 adcode（6位，如 `110000`） |
| `c` | string | 市/区 adcode（6位；直辖市为区，如 `110101` 东城区；普通省为地级市，如 `320500` 苏州）。可能为空（极少数匹配不上时） |
| `county` | string | 区县名（Wiki 原始，可为空） |
| `lng` | float | GCJ-02 经度（与底图坐标系一致，可直接用 d3 投影） |
| `lat` | float | GCJ-02 纬度 |
| `cat` | string | 分类：`red`（红色）/`hist`（人文古迹）/`modn`（现代乐园）/`nat`（自然山水） |
| `batch` | int\|null | 评定年份（2007..2024，如有） |
| `src` | string | 坐标来源：`nominatim` / `nominatim_fallback` / `manual` |

### 口径说明（README 也要写）
- 北京"八达岭—慕田峪"按官方计为 1 个 5A（北京共 9 家）。
- 乔家大院计入（山西文旅厅 2025-12 官方确认复牌）。
- 桂林乐满地不计入（2025 年被摘牌）。
- 文旅部 2026-01 公布 358 家，差异系乔家大院复牌计入时间不同，暂按 359。

## Store（src/store.js）
- 每成员新增 `spots: {}`，key 为 `5a:{id}`，value 为打卡时间戳（沿用现有 city 打卡的 value 语义）。
- Store version 升到 3，老数据迁移：`spots` 不存在则初始化为空对象。
- 5A 打卡**不**改变省/市点亮状态。打卡成功后可 toast 提示"顺手点亮该省？"但**不得**自动点亮。

## UI 需求
1. 顶部模式切换：`🗺️ 省市足迹` ⇄ `🏛️ 5A 胜迹`（分段控件样式）。
2. 5A 模式：底图变暗，359 个点为星形散点（双圆 SVG，不用滤镜）。
   - 未去过：灰色；去过：成员主题色/金色。
   - 全国视图：密集点聚合为"省/附近数量"气泡；下钻到省后散开为单点。
3. 点景点 → 底部卡片：名称、省市、分类、批次，"打卡"按钮一键打卡。
4. 省市足迹模式：点亮城市时，若该城市有 5A（按 `c` 匹配），弹出可关闭的底部卡片：
   "你点亮了{市名}，这里有 N 个 5A 景区"，列出该市 5A，点击可打卡。
   无 5A 的城市不弹卡片。
5. 进度显示：`x / 359`（从数据文件动态取长度，不要硬编码）。
6. 成就：保留现有 8 个省级称号；新增独立"名胜行者"线（阈值建议 1/10/30/80/180/359）。
